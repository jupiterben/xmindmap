# 2026-10-17

## 新增 UI 主题样式切换（浅色/深色）
- 背景：项目已有 `src/domain/themes.ts`（晴空/青林/蔷薇/石墨）是**导图节点配色**，非 UI 外观；整个 UI 外壳之前全是写死的浅色十六进制色。用户要的"主题样式切换"理解为**应用界面外观（浅色/深色）切换**。
- 实现：
  - 新增 `src/composables/useUiTheme.ts`：模块级 `theme` ref（'light'|'dark'），首次读 `localStorage['xmindmap.uiTheme']`，无则跟随 `prefers-color-scheme`；切换时给 `documentElement` 设 `data-ui-theme` 与 `color-scheme` 并持久化。
  - 重写 `src/styles.css`：引入 token 体系（--bg/--surface/--border/--text*/--accent*/--danger*/--success/--overlay/--shadow 等），`:root` 为浅色原值、新增 `[data-ui-theme="dark"]` 深色变量块；浅色完全保留原值零回归。
  - `App.vue` header 增加 Sun/Moon 切换按钮（先 `import { Sun, Moon }`，调用 `useUiTheme()` 的 `toggle`）。
- 验证：`pnpm typecheck` 无新增报错（既有报错在 AiChatPanel/files.ts/vscode-extension，与本次无关）；`vite build` 成功，深色样式已进产物 CSS。
- 注意：simple-mind-map 画布背景透明，深色模式下画布区随之变暗，节点卡片保留自身配色，观感正常。
