# XMindmap

基于 [wanglin2/mind-map](https://github.com/wanglin2/mind-map) 核心能力迁移的本地思维导图工作台，使用 **Vue 3 + TypeScript + Vite**。

## VS Code 插件

独立插件目录：[vscode-extension](./vscode-extension/README.md)。复用本项目编辑器，离线打开 `.xmindmap`、`.smm` 和导图 JSON，使用 VS Code 原生文件保存，不依赖网页服务器或 localStorage。

Windows 一键编译打包：安装 Node.js 22.12+ 后，双击仓库根目录的 `build-vscode.cmd`。脚本自动增量安装根目录和插件目录的依赖，不修改锁文件，再编译插件宿主、Webview 并生成 VSIX；安装依赖需要联网。任何步骤返回失败都会停止，并保留窗口显示错误。

也可以在终端运行（`--no-pause` 用于终端或自动化，不等待按键）：

```powershell
.\build-vscode.cmd --no-pause
```

其他平台或手动构建：

```sh
npm ci
cd vscode-extension
npm ci
npm run package
```

在 VS Code 中通过“从 VSIX 安装”选择生成的 `vscode-extension/xmindmap-0.1.0.vsix`。插件提供“新建思维导图”和“用导图编辑器打开”命令。

## 迁移方式

- 使用上游 `simple-mind-map@0.14.0-fix.3` 的成熟导图引擎及按需插件。
- 编辑器、文档管理、导入校验、持久化和引擎适配层均使用 TypeScript，开启 strict 检查。
- **不是上游引擎源码的全量 TypeScript 重写**，也不是将上游 Vue 2 页面直接复制进来。
- 不包含上游闭源桌面客户端。版权与许可见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。
- `PreciseDrag` 用 TypeScript 扩展上游拖拽插件，在松手时立即校验最终落点，避免其 300ms 节流造成快速拖拽层级错误。

## 启动

推荐 Node.js 22.12+ 或 24+，项目在 Node.js 26 下验证。

```sh
npm ci
npm run dev
```

打开终端输出的本地地址。普通导图编辑无需后端、账户或 API 密钥，文档保存在当前浏览器、当前站点的 localStorage 中。可选的 AI 功能需要单独配置模型服务。

```sh
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

`dist/` 可部署到静态站点。不同域名或端口的本地存储互相隔离。

## 核心功能

| 功能 | 实现范围 |
| --- | --- |
| 节点操作 | 新建子主题、同级主题、父主题，删除、改名、上下移动 |
| 快捷图标 | 顶部图标按钮，优先级/进度/表情/标记；同类替换、再次点击移除、清空、多选批量设置 |
| AI 对话扩展 | 常驻对话栏、自动获取模型、多轮对话、回复后自动追加子主题、停止生成、按轮撤销 |
| 画布编辑 | 双击改名，拖拽改变父子关系，平移缩放、适应画布、触摸操作 |
| 快捷键 | Tab 新建子主题、Enter 新建同级、Delete 删除、Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Y 重做 |
| 历史 | 当前文档会话最多 100 条撤销/重做记录，切换文档后重新建立历史 |
| 内容样式 | 备注、链接、标签、本地图片、字号、加粗、斜体、形状、填充和文字颜色 |
| 结构主题 | 8 种布局、4 套主题 |
| 连线样式 | 右侧主题面板选择曲线、折线或直线；独立于配色主题保存 |
| 大纲 | 定位节点、双击改名、折叠展开、搜索包含已折叠的节点 |
| 文档管理 | 多文档、新建、复制、重命名、删除确认、本地自动保存 |
| 文件导入 | JSON、SMM、Markdown |
| 文件导出 | JSON、Markdown、PNG、SVG |

画布快捷键与输入框隔离；文件保存可用 Ctrl/Cmd+S，节点搜索可用 Ctrl/Cmd+F。结构拖拽采用上游插件规则，不是自由坐标摆放。

连线样式支持思维导图、左右逻辑图、组织结构图和竖向时间轴；目录组织图、横向时间轴和鱼骨图使用布局固定连线。连线设置随本地保存、复制和 JSON 导入导出保留，旧文档默认曲线；导入 SMM 时也识别白名单内的 `theme.config.lineStyle`。

## AI 扩展

AI 对话栏是浮在画布左下角的紧凑卡片，可折叠 AI 回复，不需要点击弹出，也不会因点击画布或按 Esc 消失。属性面板默认收起，可用工具栏右侧按钮打开。数量、自动扩展开关和快捷键选项收在 AI 设置弹窗中。

默认快捷键 **Ctrl+Alt+A**（Mac：**Command+Option+A**）现在聚焦对话输入框，不发送消息。在 AI 设置里展开“快捷键设置”可更改、禁用、恢复默认。网页存入独立本地设置，VS Code 存入插件全局数据，不依赖 API Key。输入框、节点文字编辑、输入法组合输入、多选或弹窗内不会触发。仅支持 Ctrl/Command + Alt/Option（可加 Shift）+ 字母或数字；若被系统或 VS Code 占用可另选组合。

1. 选中一个节点，对话栏显示当前节点。点击齿轮打开独立 **AI 设置**；点击外部不会关闭设置或丢失输入。
2. 填写 **API 基础地址和 API Key** 后自动 GET `{baseURL}/models`，无需再点保存，也无需事先知道模型名称；获取到的模型以按钮列在设置里，点一下即可选用并保存。不填写模型时，列表首项成为初始选择；不会自动发送对话。“保存连接并获取模型”按钮仍保留，用于无鉴权服务、重新获取或改回默认地址。
3. 在对话顶部下拉框快捷切换模型，也可以选择“手动输入模型”。列表接口不兼容、为空、认证失败或 CORS 失败时显示提示，已保存 Key 不会被清空，仍可手动输入模型；在 AI 设置里重新保存即可再次获取列表。
4. 核对“发送内容”，输入消息并发送。对话栏会标明内容发往哪个地址、可能产生费用。只有发送消息并收到有效回复后，才会自动追加当前节点的子主题。回复需要澄清时可返回空主题列表，仅聊天、不改图。
5. 可以连续追问，模型会收到本次上下文及之前已完成对话。关闭“回复后自动扩展”后仅显示建议，仍可手动添加。每轮新增支持一次撤销。设置不会遮挡或关闭对话记录。

使用 AI SDK 7 和 `@ai-sdk/openai-compatible` 接入 Chat Completions，回复格式为 `{"reply":"自然语言回复","topics":["新增子主题"]}`。不执行工具或代码，仅追加一层纯文本子主题；不会根据聊天删除或重写其他节点。模型列表由服务返回，可能包含不支持聊天的模型，调用失败时可切换模型。每个节点会话最多 10 轮、历史最多 30000 字；清空对话后可继续。切换节点/文件时中止旧请求并清空会话，不把旧节点对话发送到新节点。

- **网页**：请求由浏览器直接发往配置的服务，服务需允许页面来源的 CORS 请求。API Key 只在页面会话内存中保存，刷新后需要重新输入；基础地址和模型保存在独立本地设置中。没有内置代理，不建议在公共设备或非可信页面使用长期高权限密钥。
- **VS Code**：请求由扩展宿主发送，不受浏览器 CORS 限制；API Key 使用 `SecretStorage`，仅地址和模型写入 `globalState`。AI 功能要求可信工作区及 Node.js 22+ 的扩展宿主；旧 VS Code 仍可编辑导图，调用 AI 时会提示升级。
- 改变接口地址不会自动复用其他服务的密钥；“忘记密钥”会清除当前存储。密钥不写入导图 JSON、Markdown 或图片。
- 已配置 Key 时进入页面、或在设置中同时填好地址和密钥后会获取模型元数据，不携带文档内容；只有地址或密钥被改动后才自动重新获取，打开设置本身不产生请求。模型列表最多 2000 项、响应最大 1 MB、15 秒超时，不自动重试。
- 只有发送对话才调用模型。发送当前节点（最多 2000 字）、最多 50 个已有直接子主题（各最多 200 字）、本条消息（最多 2000 字）及本会话已完成轮次，可在“发送内容”和对话记录中核对。不发送整图、备注、图片或工作区其他文件。
- 远程服务只允许 HTTPS，本机 `localhost`、`127.0.0.1`、`[::1]` 可用 HTTP。禁止 URL 内的凭据、查询参数及 HTTP 重定向，避免密钥被意外转发。
- 请求超时 60 秒，不自动重试；取消会中断请求并丢弃迟到结果，但无法撤销服务端已经产生的费用。
- 子主题拒绝 HTML、格式错误、超长条目并去重，每轮最多 10 个；回复文字按普通文本显示，不执行 HTML。插入前核对原节点未被修改、总节点数、文件大小和深度；取消、切换或删除节点不会应用迟到结果。

AI 测试使用模拟响应验证接口协议、错误、取消、密钥隔离及插入流程；没有使用真实账户或消耗模型额度。实际接入需要用户提供有效配置，生成质量以所选模型为准。

## 数据与安全

- JSON 导出保留节点、布局和主题，可重新导入；同时接受上游的裸节点树及 `{ root, layout, theme }` SMM 数据结构。
- Markdown 通过 `mdast-util-from-markdown` 解析标题和嵌套列表，导出保留层级和纯文本，不包含图片、备注或样式。
- 单文件最大 5 MB、节点最多 5,000、深度最多 80；这些是输入保护上限，不是大规模导图的性能保证。
- 图片仅接受本地 PNG/JPEG/WebP/GIF，单张最大 1 MB，以 data URL 保存。导入的远程图片不会自动加载。
- 链接只接受 HTTP、HTTPS、mailto；上游富文本导入后转换为纯文本。任意主题 CSS、远程资源地址及未实现的扩展属性不会被导入。
- 上游自定义主题在导入时使用本项目默认主题；支持的节点样式会保留。XMindmap 自己导出的四套主题可以往返保存。
- 自动保存有 350ms 防抖，切换文档、保存及页面退出时会刷新数据。存储满或无权限时会提示导出备份。
- 本地数据损坏或检测到其他标签页写入时暂停自动保存，不静默覆盖原始内容；可以备份原始数据。多标签页不支持合并编辑。
- 浏览器存储不是永久备份，建议定期导出 JSON。没有云同步和多人协作。

## 代码结构

```text
src/
  domain/            # TypeScript 文档模型、校验、序列化、Markdown、主题
  ai/                # AI SDK 调用、连接设置、取消与响应限制
  platform/          # VS Code 消息协议
  engine/            # 上游 JavaScript 的窄类型声明及命令/事件契约
  composables/       # 引擎生命周期、编辑操作、本地文档管理
  components/        # 大纲、节点属性、图标按钮
  App.vue            # 工作台页面
  styles.css         # 响应式布局与样式
tests/
  unit/              # 导入校验、数据往返、存储保护
  e2e/               # 真实浏览器编辑、导入导出、持久化、响应式测试
```

## 暂不迁移

XMind/FreeMind/PDF 文件格式、富文本与公式、关联线、概要、外框、协作、演示模式以及上游全部主题。AI 扩展是本项目独立实现，并非复制上游 AI 模块；本项目不依赖上游完整插件包。

## 依赖审计

2026-10-16 使用官方 npm registry 审计发现，上游传递依赖 `katex`、`quill`、`uuid` 仍有安全公告（共 2 个低危、2 个中危依赖条目，包含上游聚合条目）。本项目未加载公式及富文本插件；引擎使用 UUID v4。没有为消除审计提示而降级上游或跨主版本强行覆盖依赖。生产使用前仍应复核这些公告并持续跟踪上游更新。
